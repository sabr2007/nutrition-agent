## Что сделано
- **Ввод**: шаблоны дня в 1 тап (с отменой) и «по плану» прямо на «Сегодня»; текст (быстрый парсер без LLM за ~20 мс + LLM для фраз); фото с уверенностью и уточняющими вопросами; режим «на весах»; голос → транскрипция; штрихкод (фото или цифры → Open Food Facts); повтор; запись задним числом; офлайн-очередь.
- **Подсчёт**: модель только распознаёт, КБЖУ считается по базе из 192 продуктов (USDA SR Legacy, российские таблицы для творога/кефира/хлеба, казахские блюда с честными диапазонами), сырой ↔ готовый вес, защита от опасных совпадений.
- **«Сегодня»**: ккал и белок крупно, точечная «тарелка», ASCII-бары с коридором цели, остаток, чек-лист в 1 тап, журнал, прогресс челленджа.
- **Агент**: 21 типизированный инструмент, многоуровневая память (видна и редактируется, агент сам предлагает запомнить, фоновый разбор каждые 8 сообщений), 9 навыков с версиями, детерминированная подгрузка навыка по намерению, safety-слой (не ниже 1500 ккал, без компенсаций, бережное направление к специалисту), подтверждение опасных действий кнопкой, трейсы каждого запуска.
- **Проактивность**: правила-данные (DSL) + pg_cron каждые 5 минут → расписание из личного плана и контекстные правила (нет записей до 15:00, протеин после тренировки, белок к 21:00), вечерняя проверка агентом и недельный разбор; тихие часы, «отложить 15 мин», выключение правил, лимиты для сообщений агента; Declarative Web Push для iOS.
- **Провайдеры**: маршруты по задачам, fallback с circuit breaker, лог токенов и стоимости. Работает Cloudflare Workers AI; ChatGPT plan (официальный OSS-путь), Vercel AI Gateway и OpenAI подключаются флагами.
- **Данные**: журнал событий триггерами, версии приёмов, сырые входы (фото/аудио), полные ответы моделей, правки модели → персональная калибровка, метрика трения; экспорт ZIP/CSV из приложения и Parquet скриптом.
- **Приватность**: личный план (цели, шаблоны, чек-лист, правила напоминаний, распорядок, цифры тела, стартовая память) — только в `scripts/personal-seed.json` (gitignored); в репо — обезличенный пример. Публичный репозиторий начат с чистой истории.
- **P2-задел**: импорт шагов и сна из Здоровья через «Команды» (токен + эндпоинт).
- **Качество**: 44 unit-теста, 2 e2e, evals агента 10/10, CI (типы, тесты, сборка, миграции), 6 исследований с источниками.

## 3 главных решения
1. **КБЖУ считает база, LLM только распознаёт.** Цифры воспроизводимы и проверяемы, неуверенность видна (диапазоны, уверенность, вопросы), правки становятся персональной калибровкой.
2. **Один TypeScript-стек (Next.js + Supabase) с журналом событий в БД.** Один деплой, общие типы, AI SDK для агента; историю изменений гарантирует база (триггеры). Python — для анализа и экспорта.
3. **Агент = память + навыки + правила как данные, с детерминированными страховками.** Модель решает, какие инструменты вызвать, но безопасность (порог 1500, переедание), подгрузка навыков и частота сообщений от неё не зависят.

## Что сделать сейчас
1. Открыть https://ryadom-coach.vercel.app на iPhone → войти → «На экран Домой» → открыть с иконки → «Включить» напоминания.
2. Записать завтрак шаблоном и вес натощак (экран «Тело»).
3. Сделать 3–5 «размеченных приёмов» с кухонными весами — личный eval-датасет (`pnpm eval:photo --source labeled`).
4. По желанию: «Войти через ChatGPT» и Workers Paid — см. `docs/BLOCKERS.md`.

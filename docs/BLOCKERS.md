# Блокеры и шаги владельца

Обновлено: 24 ноября 2026, день. Прод работает полностью: база Supabase поднята, аккаунт создан, cron каждые 5 минут шлёт напоминания. Ниже — только то, что могу сделать не я, по порядку пользы.

## 1. «Войти через ChatGPT» (оплата лимитом подписки) — опционально 🟡

Репозиторий уже публичный под MIT (OpenAI открывает self-serve для open-source приложений). Осталось три шага, которые может сделать только владелец аккаунта ChatGPT:

1. **Форма OpenAI**: https://openai.com/form/sign-in-with-chatgpt-interest/ — вариант «Sign in and ChatGPT plan use for AI requests», ссылка на репозиторий https://github.com/sabr2007/nutrition-agent. Это подтверждение, что личное open-source приложение на Vercel может использовать твой план.
2. **Вход на своём Mac** (откроется auth.openai.com, ответ вернётся на `127.0.0.1:1455`). Команды — в [`docs/SETUP.md`](SETUP.md) → «ChatGPT plan». Токены шифруются и сохраняются только в твоей базе.
3. **Недельный лимит** для приложения: ChatGPT → Settings → Usage. Потом напиши мне (или выполни сам) `CHATGPT_PLAN_ENABLED=1` в Vercel и редеплой.

Пока этого нет, всё работает через Cloudflare Workers AI. Когда лимит подписки кончается, запросы сами уходят на следующий провайдер.

## 2. Cloudflare Workers AI: следить за бесплатной квотой ℹ️

Основной провайдер сейчас — Cloudflare Workers AI. Бесплатно: **10 000 «нейронов» в сутки**, сброс в 00:00 UTC (05:00 по UTC+5). Моя оценка расхода: фото ≈ 300–500 нейронов, сообщение коучу ≈ 500–700, вечерняя проверка агента ≈ 500. Активный день ≈ 5–10 тысяч, то есть на грани.

- Если квота кончится, до 05:00 перестанут работать фото, чат и разбор фраз моделью. Шаблоны, быстрый парсер («грудка 250»), чек-лист и напоминания по расписанию работают без моделей.
- Расход виден в дашборде: Cloudflare → AI → Workers AI.
- Если упираешься: **Workers Paid за $5/мес** (Cloudflare → Workers → Plans). Те же 10 000 бесплатно, сверх — $0.011 за 1000 нейронов, это порядка $1–3 в месяц при твоём темпе.

## 3. Vercel AI Gateway — необязательный апгрейд ⚪

Не нужен для работы. Даёт только скорость и немного точности на фото: Gemini Flash отвечает за 5–10 с вместо 20–40 с у Qwen на Cloudflare. Точность на тех же фото Nutrition5k: у Qwen по нашему eval MAPE 50%, у Gemini Flash по литературе ~44%, сами мы её не мерили. Если захочешь:
1. Vercel → AI → добавить карту (так Vercel разблокирует бесплатные кредиты): https://vercel.com/d?to=%2F%5Bteam%5D%2F%7E%2Fai%3Fmodal%3Dadd-credit-card
2. Удалить переменную `LLM_DISABLE_GATEWAY` в Vercel → Settings → Environment Variables → Redeploy.

## 4. Мелочи
- **iPhone**: Safari → войти → «Поделиться → На экран "Домой"» → открыть с иконки → на «Сегодня» нажать «Включить» напоминания. iOS разрешает пуши только по нажатию в установленном приложении. До этого напоминания видны внутри приложения.
- **Логин**: служебный адрес на домене приложения, без твоей почты (письма на него не уходят). Хочешь входить своей почтой — поменяй её в Supabase Dashboard → Authentication → Users. Новый пароль — в приложении: «Настройки → Пароль».
- **Личные данные** (рост, вес, распорядок, цели, шаблоны, правила, стартовая память) лежат только в `scripts/personal-seed.json` на твоём Mac (в git не попадает) и в твоей базе. Сделай резервную копию этого файла.
- **Старая история коммитов** (с личными заметками) осталась в приватном архиве `sabr2007/nutrition-agent-private`. Публичный репозиторий начат с чистого коммита.
- **Домен**: сейчас `ryadom-coach.vercel.app`. Свой можно подключить в Vercel → Domains.

## 1. «Войти через ChatGPT» (оплата лимитом подписки) — подключено ✅, это единственный провайдер

24.11.2026: вход выполнен, токены зашифрованы и лежат в базе. С вечера 24.11 (решение D22) **все** модели работают только на подписке: запасных провайдеров больше нет. Если лимит подписки кончится, чат и фото ответят «Лимит подписки ChatGPT исчерпан», а шаблоны, быстрый парсер («грудка 250»), ручная запись, чек-лист и напоминания по расписанию продолжат работать. Если токены протухнут, приложение скажет «нужно войти заново». Осталось два шага владельца:

1. **Форма OpenAI**, если ещё не отправлена: https://openai.com/form/sign-in-with-chatgpt-interest/ — вариант «Sign in and ChatGPT plan use for AI requests», ссылка на репозиторий https://github.com/sabr2007/nutrition-agent. Это подтверждение, что личное open-source приложение на Vercel может использовать твой план.
2. **Недельный лимит** для приложения: ChatGPT → Settings → Usage.

Повторный вход (если токены протухнут или ты выйдешь из приложения в ChatGPT) — команда в [`docs/SETUP.md`](SETUP.md) → «ChatGPT plan».

## 2. Голос: Cloudflare Whisper — только расшифровка ℹ️

У подписки ChatGPT нет распознавания речи (OpenAI это явно исключает), а встроенная диктовка iOS не работает в приложении с экрана «Домой». Поэтому микрофон в чате расшифровывает Whisper на Cloudflare Workers AI — бесплатно в дневной квоте (минута голоса ≈ 47 «нейронов» из 10 000 в сутки). Больше Cloudflare ни для чего не используется. Не нужен голос — удали `CLOUDFLARE_ACCOUNT_ID` и `CLOUDFLARE_API_TOKEN` в Vercel: микрофон ответит «расшифровка недоступна», останется диктовка с клавиатуры iPhone.

## 3. Напоминания — включить на iPhone 🟡
Открой приложение с иконки на экране «Домой» → «Сегодня» → «Включить» (iOS разрешает пуши только по нажатию в установленном приложении). До этого напоминания видны внутри приложения.

## 4. Мелочи
- **Логин**: служебный адрес на домене приложения, без твоей почты (письма на него не уходят). Хочешь входить своей почтой — поменяй её в Supabase Dashboard → Authentication → Users. Новый пароль — в приложении: «Настройки → Пароль».
- **Личные данные** (рост, вес, распорядок, цели, шаблоны, правила, стартовая память) лежат только в `scripts/personal-seed.json` на твоём Mac (в git не попадает) и в твоей базе. Сделай резервную копию этого файла.
- **Старая история коммитов** (с личными заметками) осталась в приватном архиве `sabr2007/nutrition-agent-private`. Публичный репозиторий начат с чистого коммита.
- **Домен**: сейчас `ryadom-coach.vercel.app`. Свой можно подключить в Vercel → Domains.

### Что видно
- **Функции Vercel в `iad1` (Вашингтон), база — `eu-central-1` (Франкфурт).** Каждый запрос к БД пересекает Атлантику (~90 мс), а `/api/today` делает 4 последовательных похода (проверка токена → профиль → пачка запросов дня → шаблоны/сообщения). Сам SQL — 12 мс. Перенос функций в `fra1` — главная мера.
- **supabase-js целиком в клиенте — 62,5 KB gzip** (GoTrue, PostgREST, Realtime/phoenix), хотя клиенту нужна только сессия: все данные идут через наш API.
- Экран «Сегодня» без кэша показывает «загрузка» на весь экран; `refreshInterval: 60_000` + `revalidateOnFocus` — опрос вместо событий.
- `noModule`-полифилы (38,5 KB) современные браузеры не грузят; «legacy JavaScript» ещё ~14,6 KB.
- Шрифты Literata и IBM Plex Mono — через `next/font` (subset latin + cyrillic, `display: swap`).
